# bit-0110

0と1の4桁 **bit** を操作して、黒と赤の**悪ブロック**を消していくパズルゲーム。
ビルド不要の静的サイト（HTML / CSS / 素のJavaScript）なので、GitHub Pages にそのまま置いて遊べる。

## 遊び方

タイル上に並んだブロックのうち、**悪ブロック以外は好きなマスへ動かせる**。
演算ブロックを他のブロックに**重ねる**と演算が起き、**重ねた側は消える**。

**悪ブロックのbitを `0000` か `1111` にすれば撃破。盤面から悪ブロックを全部消すとクリア。**

操作はドラッグ&ドロップ、またはタップで選んで対象をタップ。

起動するとホーム画面が出て、**つづきから**（前回のステージ）／**ステージ選択**／**あそびかた**を選べる。
クリア数と獲得した星の数もここに出る。ゲーム中はヘッダーの「ホーム」でいつでも戻れる。
右下の**データを初期化**で、クリア状況・星・チュートリアルの表示履歴を消して最初から遊べる（確認あり）。

ルールは文章ではなくチュートリアルで覚える。**そのブロックが盤面に初めて出てきたステージ**で
自動的に開く（ステージ選択で先へ飛んだ場合も、未見のブロックの説明がまとめて出る）。

チュートリアルは「**動かす + 重ねる先 = 結果**」の3枠を並べたまま演出する。
**ブロックは自分で掴んでドラッグできる**ので、自分のペースで動かして確かめられる
（掴むと自動再生は止まる）。落とすと使ったブロックが薄くなって「使って消えた」に、
重ねる先のラベルが `0101 → 1111` に変わる。演出が終わっても式がそのまま残るので、
いつ見ても「何を・どこに動かして・どうなったか」が分かる。
触らなければ4.4秒ごとにお手本が自動で流れ、「もう一度」でいつでも最初から試せる。
一度見たら再表示されず、ヘッダーの「あそびかた」からいつでも見返せる。

## ブロック

| ブロック | 色 | bit | 効果 |
|---|---|---|---|
| 悪 | 黒地に赤 | あり | 動かせない。`0000` か `1111` になると消える |
| OR | 薄黄緑 | あり | 自分が1のところを1にする　`0101 + OR 1010 → 1111` |
| AND | 水色 | あり | 自分が0のところを0にする　`0110 + AND 1001 → 0000` |
| XOR | 橙 | あり | 自分が1のところを反転する　`0101 + XOR 0101 → 0000` |
| NOT | 白 | **なし** | 相手の0と1を全部ひっくり返す　`0110 → 1001` |

演算ブロック同士も重ねられる。種類は**重ねられた側**のまま、bitだけが変わる。

```
OR 1100 + OR 0011 → OR 1111        同じ種類なら bit が合成される
AND 0110 + NOT    → AND 1001       NOT で道具を作り替える
```

NOTはbitを持たないので、**NOTを演算の対象にはできない**。
ブロックは使うと消えるため、無駄打ちすると詰む。詰んだ盤面はソルバーが自動で検出して
**GAME OVER 画面**を出し、「やりなおす」「ステージ選択」「1手もどす」から選べる。

クリアしたステージには、ステージ選択画面のボタン右上に星がつく。
**青い星**＝クリア済み、**金の星**＝最短手数でクリア。

## ステージ

全310ステージ、4ワールド構成。新しいブロックが1種類ずつ解禁され、ワールド内でも後半ほど難しくなる。

| ワールド | ステージ | 使えるブロック | 難易度 |
|---|---|---|---|
| OR編 | 1〜10 | OR | 最短1〜5手。悪1体のうちは詰まない練習面 |
| NOT編 | 11〜60 | OR, NOT | 最短2〜6手。NOTでORを作り替える面が登場 |
| AND編 | 61〜160 | OR, NOT, AND | 最短2〜6手。0000側で撃破する道が加わり、悪3〜4体が標準に |
| XOR編 | 161〜310 | 全種 | 最短2〜7手。終盤は詰み率9割超、ほとんどの初手が罠 |

各ワールドの序盤は新ブロックの導入面（その**ブロックなしでは解けない**盤面だけを採用）、
中盤からは**演算ブロック同士の合成なしでは解けない**面が中心になる。

ステージは `scripts/generate-levels.js` が自動生成する。難易度スペック（悪・道具の数、最短手数、
詰み率、合成必須、必須ブロック）を満たす盤面を固定シードのランダムサンプリング＋ソルバー検証で
探しているので、出力は決定的で、全ステージが `test/verify.js` の機械検証を通っている。

```sh
node scripts/generate-levels.js              # 310面すべて再生成
node scripts/generate-levels.js --worlds 2   # 最初の2ワールドだけ
```

## ホーム画面に追加して遊ぶ

`manifest.webmanifest` とアプリアイコン（`icons/`）を用意してあるので、
iOS/Android のブラウザから「ホーム画面に追加」するとアプリのように全画面で起動する。
**縦画面・横画面のどちらにも対応**していて、横画面では盤面の横に情報とボタンが並ぶ。

## GitHub Pages で公開する

このリポジトリは `main` ブランチのルートに `index.html` を置いた静的サイトなので、設定だけで公開できる。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` にする
3. **Branch** を `main` / `/ (root)` にして **Save**

数十秒後に `https://<ユーザー名>.github.io/bit-0110/` で遊べるようになる。

## 開発

```
bit-0110/
├── index.html          画面
├── manifest.webmanifest  ホーム画面に追加したときの設定
├── icons/              アプリアイコン（32/180/192/512, maskable）
├── css/style.css       見た目
├── js/core.js          ルール本体とソルバー（ブラウザ・Node 両対応）
├── js/levels.js        ステージデータ（自動生成。手で編集しない）
├── js/tutorial.js      視覚チュートリアル（デモのアニメーションと中身）
├── js/ui.js            描画とドラッグ / タップ操作
├── scripts/
│   └── generate-levels.js  ステージ生成器（難易度スペック→盤面探索）
└── test/
    ├── verify.js       全ステージをソルバーで検証（Nodeのみ）
    └── browser.js      実ブラウザでサンプルステージを通しプレイ（Playwright）
```

ローカルで遊ぶだけなら `index.html` をブラウザで開けばよい（進行状況の保存にはローカルサーバー推奨）。

```sh
npx http-server .        # http://localhost:8080

node test/verify.js      # 全310面をソルバー検証（--verbose で1面ずつ表示）
node test/browser.js     # ブラウザでの通しプレイ（要 playwright）
```

`test/verify.js` は次を確認する。

- 盤面の整合性（盤外・壁の上・座標の重複・bitの書式・ワールドで許可された種類か）
- 全ステージが解けること、`par` が実際の最短手数と一致すること
  （ゲーム内実装 `Core.solve` と、テスト内の独立実装ソルバーの両方で）
- 全到達状態について、独立ソルバーの答えが「クリアから逆向きの不動点計算」と一致すること
- ヒントの初手が最短を崩さないこと（節目のステージはヒントだけで最後まで完走）
- ワールド内で難易度（par・詰み率）が段階的に上がっていること、同一ステージがないこと

### ソルバーについて

ブロックはどのマスへでも動かせて、重ねるのに隣接も不要なので、**位置は解けるかどうかに影響しない**。
そのため状態は「悪ブロックのbitの多重集合」＋「演算ブロックの多重集合」だけで表せる。
1手ごとに演算ブロックが必ず1つ消えるので探索木は有限で閉路もなく、メモ化した深さ優先探索で最短手数が求まる。
これを使ってゲーム内の詰み検出とヒントを実装している。
